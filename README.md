# Storytime Near Me

A single-page web app listing free baby/toddler library storytimes near San Diego,
filterable by distance, child age, language, day, and time.

**Live site:** https://chav-antonio.github.io/storytime-near-me-site/

This repository holds the published static site only — `index.html` and the `data/`
payloads. Open `index.html` directly in a browser, or serve the folder over HTTP:

```bash
python -m http.server 8000   # then visit http://localhost:8000/index.html
```
